# Mutsuki v0.1.0 compatibility matrix

This release is the first unified monorepo baseline. All listed packages are sourced from the same
Git tag and root `Cargo.lock`.

| Group | Compatibility contract |
| --- | --- |
| Runtime contracts/wire/core | Batch-first Task/Runner, typed wire, TaskHandle, ResourceRef and LoadPlan |
| Link | Stable typed session/channel contracts; optional Local/TCP/QUIC transports |
| Service/CLI | Authenticated control API, lifecycle, plugin loading and runner supervision |
| Tauri/Web | Host bridges consume public runtime contracts; frontend packages are precompiled |
| Distributed | Optional sidecar only; no distributed types or branches enter Core |
| AgentKit | Agent protocols and runners use runtime Task/Runner surfaces |
| Bot packages | Bot protocols, adapters and explicit ServiceHost integration |
| Standard plugins | Domain-neutral protocols/providers/effects/workflows |
| Python Runner Kit | Mirrors the runtime wire artifacts from this tag |
| Bot template | Generated from `templates/bot`, published to `MutsukiBotTemplate`, and pins this tag |

External consumers must use `https://github.com/sena-nana/Mutsuki.git` with tag `v0.1.0` or the
release commit. Former framework repository revisions are not a supported mixed baseline.
