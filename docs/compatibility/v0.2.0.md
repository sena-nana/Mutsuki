# Mutsuki v0.2.0 compatibility matrix

This release is the first complete AgentKit Runtime / Adapter / Plugin baseline. All listed
packages are sourced from the same Git tag and root `Cargo.lock`.

| Group | Compatibility contract |
| --- | --- |
| Runtime contracts/wire/core | Batch-first Task/Runner, typed wire, TaskHandle, ResourceRef and LoadPlan |
| Link | Stable typed session/channel contracts; optional Local/TCP/QUIC transports |
| Service/CLI | Authenticated control API, lifecycle, plugin loading and runner supervision |
| Tauri/Web | Host bridges consume public runtime contracts; frontend packages are precompiled |
| Distributed | Optional sidecar only; no distributed types or branches enter Core |
| AgentKit Contracts/Runtime | Versioned Agent DTOs, profile, session/turn/approval/checkpoint semantics |
| AgentKit Adapter/Plugin | Provider-neutral authoring API, explicit Provider instances, Mutsuki plugin generation |
| AgentKit Client | Agent wire over the MutsukiLink control stream with version/feature negotiation |
| Agent durable/distributed | `mutsuki-protocol-db` and DistributedHost service contracts; no embedded infrastructure |
| Bot packages | Bot protocols, adapters and explicit ServiceHost integration |
| Standard plugins | Domain-neutral protocols/providers/effects/workflows |
| Python Runner Kit | Mirrors the runtime wire artifacts from this tag |
| Bot template | Generated from `templates/bot`, published to `MutsukiBotTemplate`, and pins this tag |

External consumers must use `https://github.com/sena-nana/Mutsuki.git` with tag `v0.2.0` or the
release commit. Former framework repository revisions are not a supported mixed baseline.

The v0.2.0 Rust DTO source surface boxes selected large AgentKit enum payloads. Rust consumers
must construct and match those boxed variants directly. This representation change does not alter
serde JSON, protocol identifiers, wire schemas, or Python mirrors, and does not require a wire or
schema version increase.

AgentKit package set `v0.1.0` does not support mixing contracts/runtime/adapter/plugin crates from different
revisions. Production bundles contain no implicit Provider. The full capability statement and
SemVer policy are in `kits/agent/docs/release-v0.1.0.md`.
