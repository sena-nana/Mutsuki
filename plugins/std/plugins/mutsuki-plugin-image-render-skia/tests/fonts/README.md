# Test font

`NotoSansSC-Test.ttf` is a test-only subset of Google Fonts' `Noto Sans SC`
variable font. It contains only the Latin and CJK glyphs exercised by this
crate's behavior tests. The subset was produced with fonttools and remains
licensed under the SIL Open Font License 1.1 in `OFL.txt`.

Source: <https://github.com/google/fonts/tree/main/ofl/notosanssc>
