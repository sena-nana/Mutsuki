# Test font

`NotoSansSC-Test.ttf` and `NotoSansSC-Bilibili-Test.ttf` are test-only subsets
of Google Fonts' `Noto Sans SC` variable font. They contain only the Latin and
CJK glyphs exercised by the established Mihuashi baseline and the Bilibili
card baseline respectively. The subsets were produced with fonttools and
remain licensed under the SIL Open Font License 1.1 in `OFL.txt`.

Source: <https://github.com/google/fonts/tree/main/ofl/notosanssc>
